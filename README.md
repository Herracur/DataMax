# DataMax

**A simple and flexible DataStore framework for Roblox, written in Luau.**

DataMax is designed to make data management easier, more flexible, and more convenient. Store the data you need, manage multiple DataStores with ease, and use caching to keep frequently accessed data readily available when you need it most.

With a simple and intuitive API, DataMax helps reduce repetitive code and simplifies the way you handle player data. Instead of manually managing data saving across multiple server scripts, you can configure your stores once and let DataMax handle the rest.

Once configured, your stores can be managed through a single framework, with automatic saving designed to save a player's data when they leave the game.

Our goal is to provide developers with a straightforward and reliable way to manage player data without unnecessary complexity.

## ⚠️ Development Status

**DataMax is currently in Alpha.**

The framework is still under active development, and some features may be incomplete or subject to change. Bugs and unexpected behavior may occur. More features, improvements, and optimizations are planned for future updates.

Use with caution in production environments, and always test thoroughly before relying on DataMax for important player data.

More documentation and usage examples will be added as development progresses.
